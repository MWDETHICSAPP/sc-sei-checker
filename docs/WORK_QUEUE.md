# Ethics Compliance Portal
## Work Queue

**Version:** 1.0 (Working Draft)

---

# Purpose

The Work Queue is the primary operational spreadsheet and staff-facing list produced by a batch compliance review.

Each row represents one person.

The Work Queue summarizes that person’s complete Compliance Profile for the selected reporting year and the applicable rolling four-year review period.

---

# Batch Information

Each Work Queue must identify:

- Batch name
- Reporting year
- Review date
- Beginning date of the rolling four-year period
- Source spreadsheet
- Number of people reviewed

---

# Person Columns

Each row should include:

- Person name
- Office
- Jurisdiction
- Filing basis or filing bases
- Manual review required
- Overall review status

Possible filing bases include:

- Elected Official
- Candidate
- Appointed Official
- Public Employee

A person may have more than one filing basis.

---

# SEI Review Columns

The Work Queue must show every SEI due within the applicable four-year period.

For each SEI year, the Work Queue should identify:

- Required
- Filed
- Filing date
- Timeliness
- Missing
- Manual review required

A person may have up to four missing SEIs within the rolling four-year period.

---

# Campaign Review Columns

Campaign reporting must be evaluated separately for each run for office.

For each campaign, the Work Queue should identify:

- Office sought
- Election year
- Campaign status
- Initial report date
- Final report date
- Open or closed run
- Number of required campaign reports
- Number filed timely
- Number filed late
- Number missing
- Manual review required

A person may have multiple simultaneous campaigns.

---

# Campaign Detail

The primary Work Queue may summarize campaign deficiencies by person.

A separate Campaign Detail worksheet should list each required campaign report individually, including:

- Person name
- Campaign
- Report type
- Reporting period
- Original due date
- Grace-period deadline
- Filing date
- Filing status
- Within the four-year period
- Manual review required

---

# Objective Statuses

Possible filing statuses include:

- Filed Timely
- Filed Late
- Missing
- Not Required
- Outside Review Period
- Manual Review Required

The Portal must not label a person as having committed a violation.

---

# Letter Status

Each person’s row should identify:

- No Letter Needed
- Draft Letter Available
- Manual Review Before Letter
- Staff Review Complete
- Letter Approved
- Letter Sent

The Portal generates one draft letter per person containing all identified objective deficiencies.

---

# Relationship to Compliance Profile

The Work Queue is generated from the Compliance Profile.

The Work Queue and deficiency letter must always reflect the same underlying filing results.

The spreadsheet is an operational output and must remain downloadable.
